# Manual de GoProject

Manual de referencia de la plataforma GoProject (Edelvives), como sitio estático.

- **Web:** https://goproject-manual.vercel.app
- **Editar:** modifica `index.html` (las imágenes están en `manual_assets/`).
- **Publicar:** `git commit` + `git push` → Vercel despliega automáticamente.
